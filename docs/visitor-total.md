# Footer visitor total

The footer displays a Google Analytics snapshot from `config/site.json` → `visitor_total`. The initial total is 287, verified on 28 October 2026 in property 549530905 using Total users, with Hostname exactly matching brief.hamelberg-ai.com, for 1 September–28 October 2026.

To refresh, read Total users for that same hostname and a cumulative date range beginning 1 September 2026, then replace count, period_end, period_label and updated_at together. Do not sum daily users: returning users would be double-counted. Do not substitute the entire property total, sessions or page views.

This is a dated snapshot, not an automatic GA Data API connection. The footer makes no additional tracking requests and displays the reporting period. Publication renders the snapshot on every page from the shared base template.
