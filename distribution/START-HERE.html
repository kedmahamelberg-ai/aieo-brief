Install into aieo-brief.
This is the separate Brief repository. Keep the Observatory in its existing repository.

1. Copy the website update

  1. In GitHub Desktop, select aieo-brief under Current Repository. If missing, use File → Clone Repository and select it.
  2. Choose Repository → Show in Finder. This shows the folder you will select next.
  3. Double-click INSTALL-BRIEF.command in this download. Select that existing aieo-brief folder. Choose Use current settings.
  4. Return to GitHub Desktop. Enter Upgrade the Brief in Summary, then click Commit to main → Push origin.
If the installer does not open

Open Terminal. Type bash, then a space. Drag INSTALL-BRIEF.command into Terminal and press Return. A folder chooser will appear.

The installer verifies the files and saves a backup beside your repository. It does not push changes or run database queries.

2. Connect the database and publishing once

  1. Copy all the text from this database setup file. In your existing Supabase → SQL Editor → New query, paste it and click Run. Then run the second database file in a new query.
  2. In aieo-brief → Settings → Pages, select GitHub Actions. A private repository needs an eligible GitHub plan for Pages.
  3. In Settings → Secrets and variables → Actions → Variables, create BRIEF_PUBLISH with value true. Retain the existing Supabase secrets in the Secrets tab.
  4. Go to Actions → Update Brief News and Research → Run workflow. Also run Update Brief Daily Culture once. Both workflows start Build and Publish AIEO Brief when they finish. The deploy job provides the live website link.

A green build with a skipped deploy means the website was built but publishing is not enabled. The default website address is https://kedmahamelberg-ai.github.io/aieo-brief/.

3. Switch on your chosen services

Use the settings form for email sign-in, Google Analytics, and automatic Google advertising. It downloads Brief-Settings.json. Run the installer again, select Choose settings file, choose that file, then commit and push.

Public email sign-in needs Supabase mail delivery and redirect settings. Ads need your approved advertising account and consent message. Follow the exact steps in OWNER-SETUP.md when connecting these services. The reading website can operate while you set them up.

What goes to GitHub?

The installer copies the contents of Repository to your existing aieo-brief clone. It preserves your settings unless you choose new ones. The preview, installer and download instructions can stay in Downloads.

Only the generated website is published. Private article bodies, database credentials and editorial support quotes are excluded.
